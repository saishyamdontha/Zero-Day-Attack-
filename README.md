# Zero-Day-Attack- (archived course project)

Original BTH Advanced ML group project: network-layer detection on CIC-IDS 2017 (association
rules on sliding windows) and host-layer detection on ADFA-LD system calls, fused with OR logic.

**Superseded.** This evaluation tuned detection thresholds on test data, so its reported
recall is not a valid estimate. The host-layer work was rebuilt with a held-out protocol in
[syscall-ids-benchmark](https://github.com/saishyamdontha/syscall-ids-benchmark).
